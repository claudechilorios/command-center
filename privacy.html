Privacy Policy

Command Center Gmail · last updated 2 October 2026

Command Center Gmail is a personal tool run by one person on their own computer. It has a single user, who is also its author. There are no accounts, no sign-up, and no way for anyone else to use it.

What it accesses

With the gmail.modify permission, and only against the account that authorised it, the tool:

  • lists unread messages in the inbox;
  • reads the sender, subject, and body of those messages;
  • extracts text from attachments where they contain text;
  • marks messages as read once handled.

It does not send mail, delete mail, or touch anything outside the inbox.

What it does with it

Message text is sent to Anthropic's API to produce a short summary and decide which project the mail belongs to. That summary is written to a notes file on the author's own computer. The identifiers of handled messages are stored locally so the same mail is not processed twice.

Where it is stored

Summaries and message identifiers are stored as ordinary files on the author's personal machine. No database, no server, no cloud storage. Nothing is uploaded anywhere except the API call described above.

Who else sees it

Anthropic processes message text to generate summaries, under their own terms. Beyond that, nothing is shared, sold, published, or disclosed to anyone. There are no analytics, no trackers, and no advertising.

How long it is kept

Summaries stay in local files until the author deletes them. Because everything lives on one personal machine, deleting those files removes the data entirely.

Withdrawing access

Access can be revoked at any time from Google Account permissions. Revoking it stops all access immediately.

Limited Use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
