Command Center Gmail

A personal tool that files email into project notes.

Command Center is a set of local dashboards I run on my own Mac to manage a handful of projects. This page exists because one part of it reads my Gmail, and Google requires any application requesting Gmail access to publish a homepage and a privacy policy.

What it does

Every couple of minutes it checks my inbox for unread mail. For each new message it works out which project the mail relates to, writes a short summary into that project's notes file on my computer, and marks the message as read. Mail that doesn't match a project is marked read and ignored.

Who it is for

One person — me. It runs on localhost, is not distributed, has no sign-up, and no one else can use it. It is published in Google's console only because an application that touches Gmail has to be, even when its only user is its author.

Where the data goes

  • Email content is summarised, and the summaries are stored as files on my own machine.
  • Message text is sent to Anthropic's API to produce those summaries.
  • Nothing is published, sold, shared, or sent anywhere else.

Full detail is in the privacy policy.
